# O'zbekiston buxgalteriya telegram boti

## O'rnatish

1. Python 3.10+ o'rnating.
2. Paketlarni o'rnating:
   pip install -r requirements.txt
3. `.env` fayl yarating va Telegram bot tokenini kiriting:
   BOT_TOKEN=your_token_here
   ADMIN_ID=your_chat_id
4. Botni ishga tushiring:
   python main.py

## Xususiyatlar

- Excel fayllarni qabul qiladi
- Balans, daromad va naqd pul hisobotlarini yaratadi
- Telegram interfeysi orqali ishlaydi
